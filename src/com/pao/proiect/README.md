# Proiect PAOJ biblioteca
Proiectul implementeaza in limbajul Java un sistem de management pentru o biblioteca.

## Tipuri de obiecte
- Angajat (abstract)
- Autor
- Bibliotecar
- Carte
- Cititor
- Imprumut
- ISBN (id pentru Carte)
- PersonalRaft
- Review
- Sectiune

Total: **10**

## Actiuni si interogari

1. Adauga o carte
2. Listeaza cartile alfabetic
3. Adauga un cititor
4. Imprumuta o carte
5. Returneaza o carte
6. Adauga un review
7. Afiseaza review-urile unui cititor
8. Afiseaza cartile neintoarse la timp pt. un cititor
9. Arata nr. mediu de stele pt. o carte
10. Adauga un angajat
11. Listeaza angajatii
